# 🚨 Smart Campus Surveillance and Guidance System

A Python-based Smart Campus Surveillance and Guidance System designed to improve campus safety and monitoring using computer vision, real-time alerts, camera streaming, and IoT sensor simulation.

## 📌 Project Overview

The Smart Campus Surveillance and Guidance System provides a centralized platform for monitoring campus environments.

The system combines camera monitoring, object detection, IoT sensor data, and real-time alerts through a web-based dashboard.

## ✨ Features

- 📹 Real-time camera monitoring
- 🔍 Object detection
- 🚨 Real-time alert generation
- 🌡️ IoT sensor data simulation
- 📊 Web-based monitoring dashboard
- 🎥 Camera streaming
- 🏫 Smart campus monitoring
- ⚡ Real-time system updates

## 🛠️ Technologies Used

- Python
- Flask
- OpenCV
- YOLO
- HTML
- CSS
- JavaScript
- IoT Sensor Simulation
